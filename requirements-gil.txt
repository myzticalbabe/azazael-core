# These are the frameworks that publish NO cp314t (free-threaded) wheel, so
# they cannot run on the Ubuntu pillar's primary interpreter
# (/usr/local/python314t, CPython 3.14.7 free-threading). They install into the
# GIL sidecar instead — a same-version GIL build (cpython-314):
#
#     interpreter : /usr/local/python3147-gil/bin/python3.14
#     entry point : /usr/local/bin/python3.14-gil
#     venv        : /root/venv-314-gil
#
# Resolution logic lives in src/CORE/python_env.py; see also
# /root/PYTHON_CONSOLIDATION_2026-09-30.md.
#
# On the Docker image (python:3.14-slim-bookworm is the standard GIL build)
# these install directly into the container interpreter. To rebuild the WSL
# sidecar:  bash scripts/rebuild_gil_sidecar.sh
#
# NOTE: onnxruntime, xgboost, lightgbm and scikit-learn DO have cp314t wheels
# and are already covered by requirements_314_full.txt on the primary. They are
# deliberately NOT repeated here.
# ---------------------------------------------------------------------------
