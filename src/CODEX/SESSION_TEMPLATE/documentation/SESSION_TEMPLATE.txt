# Session Flow Report - Reproducibility Template

## Purpose
This template enables future assistants to generate interconnected web HTML reports displaying any session's operations, documented failures, and visual flow diagrams.

## Template Types
1. **GRID WEB** - For displaying items in organized rows/columns (see Section A)
2. **HIERARCHICAL WEB** - For showing logical derivation/dependency (see Section B)

---

## SECTION A: GRID WEB TEMPLATE

### Quick Start

## How to Fill Template

### Order of Operations
- Use `<ol>` with `<li>` items
- Format: `[STEP]: [command or action] - [details]`
- Example: `1: netstat -ano - Check port usage`

### Documented Failures
- Use `<ul>` with `<li>` items
- Format: `[Issue]: [Description of problem]`
- Example: `Permission denied: EPERM on file edit`

### Web Bubbles (Visual Flow)

**Bubble Syntax:**
```html
<div class="bubble phase-N" style="width:100px;height:100px;left:X%;top:Y%;">TEXT</div>
```

| Attribute | Description |
|----------|-------------|
| phase-N | Color class (1-8) |
| width/height | Bubble size in pixels |
| left | Horizontal position (0-100%) |
| top | Vertical position (0-100%) |

**SVG Connection Syntax:**
```html
<line class="connection" x1="10%" y1="5%" x2="25%" y2="5%"/>
```

## SECTION B: HIERARCHICAL/LOGICAL WEB TEMPLATE

Use this template when you need to show LOGICAL DERIVATION or DEPENDENCY between items (like environment variables, system hierarchy, etc.)

### Key Features:
- **Levels** (0-7): Show derivation hierarchy from root to leaves
- **Connection Types**:
  - `derive`: Solid teal line - derivation/inheritance
  - `parent`: Dashed red line - parent-child relationship  
  - `same`: Yellow line - same-level connections

### Level Colors:
```css
.lvl0 { background: linear-gradient(135deg, #2d3436, #000); color: #fff; }  /* Kernel/Root */
.lvl1 { background: linear-gradient(135deg, #6c5ce7, #4834d4); color: #fff; }  /* System */
.lvl2 { background: linear-gradient(135deg, #00b894, #00a085); color: #fff; }  /* User */
.lvl3 { background: linear-gradient(135deg, #fdcb6e, #f39c12); }  /* Derived */
.lvl4 { background: linear-gradient(135deg, #e17055, #d63031); color: #fff; }  /* Process */
.lvl5 { background: linear-gradient(135deg, #fd79a8, #e84393); color: #fff; }  /* App */
.lvl6 { background: linear-gradient(135deg, #74b9ff, #0984e3); color: #fff; }  /* PATH */
```

### Syntax:
```html
<!-- Legend -->
<div class="legend">
  <div class="legend-item"><div class="legend-dot" style="background:#2d3436"></div>Level 0: Kernel</div>
  <!-- ... more levels -->
</div>

<!-- Connection lines -->
<svg class="connections">
  <line class="derive" x1="50%" y1="3%" x2="50%" y2="8%"/>
  <line class="parent" x1="20%" y1="12%" x2="10%" y2="18%"/>
  <line class="same" x1="20%" y1="12%" x2="50%" y2="12%"/>
</svg>

<!-- Level bubbles -->
<div class="bubble lvl0" style="width:80px;height:80px;left:46%;top:1%;">ROOT</div>
<div class="bubble lvl1" style="width:70px;height:70px;left:15%;top:10%;">LEVEL1</div>

<!-- Tooltip on hover -->
<div class="bubble lvl1" style="width:70px;height:70px;left:15%;top:10%;">TEXT
  <div class="tooltip">Detailed info<br/>Line 2<br/>Line 3</div>
</div>
```

### Example: Environment Variables Hierarchy
```
Level 0: KERNEL (OS, SYSTEMROOT)
    ↓
Level 1: SYSTEM (WINDIR, HARDWARE, NETWORK)
    ↓
Level 2: USER (USERNAME, USERPROFILE)
    ↓
Level 3: DERIVED (APPDATA → TEMP)
    ↓
Level 4: PROCESS (OPENAI_API_KEY)
    ↓
Level 5: APP (Git, Python installations)
    ↓
Level 6: PATH (executable search paths)
```

## QUICK REFERENCE
================================================================================

### To create a GRID WEB report:
1. Copy Section A HTML template
2. Replace [INSERT SESSION TITLE] with your title
3. Add steps to ORDER OF OPERATIONS list
4. Add failures to DOCUMENTED FAILURES list
5. Add bubbles with class "phase-1" through "phase-8"
6. Add SVG lines to connect bubbles

### To create a HIERARCHICAL WEB report:
1. Copy Section B HTML template
2. Use lvl0-lvl6 classes for hierarchy levels
3. Use "derive", "parent", "same" for connection types
4. Add tooltips for detailed information

### Common Issues:
- Syntax error: Ensure `left:X%` not `left="X%"`
- Bubbles not showing: Check z-index and position values
- Lines not connecting: Verify x1,y1,x2,y2 percentages
