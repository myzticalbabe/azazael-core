  1. 1: netstat -ano findstr 1234 - Check if port 1234 is in use
  2. 2: ping -n 1 localhost - Test DNS resolution for localhost
  3. 3: curl 127.0.0.1:1234 - Test IPv4 connection to localhost
  4. 4: curl localhost:1234 - Test hostname connection
  5. 5: notepad C:\Windows\System32\drivers\etc\hosts - Open hosts file for inspection
  6. 6: Found: # 127.0.0.1 localhost - Root cause: localhost entries commented out with #
  7. 7: Set-Content hosts -Value '127.0.0.1 localhost' - EPERM: Access denied without elevation
  8. 8: New-Item -Path fix_hosts.ps1 - Create PowerShell script for automated fix
  9. 9: powershell -Verb RunAs -File fix_hosts.ps1 - Request administrator elevation
  10. 10: Set-Content hosts (uncommented entries) - Write fix with elevated privileges
  11. 11: 127.0.0.1 localhost - Add IPv4 localhost mapping
  12. 12: ::1 localhost - Add IPv6 localhost mapping
  13. 13: Remove-Item fix_hosts.ps1 - Clean up temporary script
  14. 14: python -c "import requests; requests.get('http://localhost:1234')" - Test HTTP connection from Python
  15. 15: Response: HTTP 200 OK - Connection verified successful
  16. 16: pip uninstall lite-llm -y - Remove malformed package (typo)
  17. 17: pip uninstall litellm -y - Remove any existing litellm package
  18. 18: pip install litellm - Fresh install of correct package
  19. 19: setx OPENAI_API_KEY dummy - Initialize environment variable
  20. 20: setx OPENAI_API_KEY sk-lm-... - Set actual LM Studio API key
  21. 21: Registry: HKCU\Environment\OPENAI_API_KEY - Persist to Windows registry
  22. 22: taskkill /IM 'LM Studio.exe' /F - Force terminate LM Studio
  23. 23: Start-Process 'LM Studio' - Launch LM Studio application
  24. 24: Load llama-3.2-1b-instruct-q4_k_m - Load AI model into memory
  25. 25: Start server at localhost:1234/v1 - Enable OpenAI-compatible API
  26. 26: grep -r PYTHONPATH C:\Users\clint\Desktop\Azazael_UNIFIED - Search for PYTHONPATH in Azazael files
  27. 27: Found: PYTHONPATH=C:/Users/clint/Desktop/Azazael_UNIFIED - Path conflict detected causing import issues
  28. 28: setx PYTHONPATH "" - Clear PYTHONPATH environment variable
  29. 29: Remove-ItemProperty HKCU:\Environment PYTHONPATH - Remove from registry permanently
  30. 30: os.environ['OPENAI_API_KEY'] = 'sk-lm-...' - Set API key in Python code directly
  31. 31: litellm.completion(messages=[...], model='openai/llama-3.2-1b-instruct') - Call LiteLLM completion API
  32. 32: model='openai/llama-3.2-1b-instruct' - Specify model for LiteLLM
  33. 33: Response: 'Hello! I am Qwen, how can I help you today?' - SUCCESS: API working correctly
